## Findings

1. **Stale entries for deleted files pass silently.** An entry for `src/features/gone/index.tsx`, where that file does not exist, produces no problem. The code comment says "Stale entries fail the gate", so the claim is false. Only entries for leaves that exist and are mounted are checked (`leaf-guard.mjs`, the `mounted.has(leaf)` branch). Fix: every allowlist path must exist as a leaf file in `src/`, or it is a stale-entry problem. Add a negative test.

2. **A leaf imported only by an unreachable file counts as mounted.** Fixture: `src/features/zz-a/index.tsx` (default export) is imported only by `src/features/zz-b/helper.tsx`, and nothing imports `helper.tsx`. The guard reports no problem for `zz-a`. The rule's stated purpose is "a screen nobody can reach", so this hole defeats it. Fix: compute reachability from the real roots (`src/main*`, `src/app/routes*`, the container files), and count only files reachable from those roots. Add a negative test for the transitive case.

Minor, not blocking: the placeholder regex is per line, so a multi-line `<h1>\n  Index\n</h1>` passes. It also flags any line containing the placeholder, not only a lone-h1 body. The docs say "lone", so either tighten the match or reword the doc comment.
