## Findings

### F1 — HIGH (security): API key leaks through transport error messages

- **Where:** `src-tauri/crates/boba-sources/src/http/mod.rs` — the error arms that build `SourceError::Http { message: error.to_string() }` in `send_with_retry`, `send_post_with_retry`, and `to_response` (body read). `src-tauri/crates/boba-sources/src/feeds/api.rs:95` (`redact`) replaces only the `url` field and keeps `message`.
- **Why:** reqwest's `Display` appends ` for url (<full url>)` to every error that has a URL (reqwest-0.13.5, `src/error.rs:257-309`). Jooble's key is a path segment (`/api/<key>`) and Adzuna's is a query parameter, so a connect or timeout failure after retries yields a message containing the key. `redact()` then keeps that message. The error is carried in `SourceFetch::Err` and recorded to `source_run`, which takes an error string.
- **Repro:** `Jooble::test_with("secret-key-123", "http://127.0.0.1:1", RateLimits::default())`, then `search()`. The connect fails and the error text contains `127.0.0.1:1/api/secret-key-123`. Expected: the text contains `<key>` and not the key. The existing `an_error_never_carries_the_key` test only covers a 500, which has no URL in its message, so it does not catch this.
- **Fix:** strip the URL from reqwest errors before stringifying: `error.without_url().to_string()` in the three arms (reqwest provides `Error::without_url`). Apply it in both `get` and `post` paths so Adzuna is covered too. Add a regression test for Jooble and one for Adzuna against a closed port, asserting that the key is absent from `error.to_string()`.

### F2 — MEDIUM: `https_url` is copied, not reused

- **Where:** `src-tauri/crates/boba-sources/src/feeds/api.rs:179`.
- **Why:** the granted scope said to reuse S4.5's validator. `ats::json::https_url` (`ats/json.rs:87`) is the same logic, and the copy is a drift risk for a security check.
- **Fix:** make `ats::json::https_url` visible to `feeds` (`pub(crate)` is already enough) and delete the local copy. Keep the feed tests.

## Verified (no finding)

- **`post()` hardening parity (granted scope):** the same token bucket and interval, daily budget check, shared client (timeout, UA, no redirects), body cap through `to_response`, and no conditional-cache write for POST.
- **Safe retry semantics:** POST replays only on connect errors (the request never reached the server) and on 429/503 that carry `Retry-After`. Bare 5xx and timeouts are not replayed, so a side effect cannot be doubled.
- **`https_url` coverage:** all six feeds and both aggregators (Adzuna `redirect_url`, Jooble `link`) pass `apply_url` through the validator and fall back to a self-built https URL. Fixtures cover `javascript:` and `http:`.
- **`detail.tsx` guard:** a link renders only when `isHttpsUrl` is true. Anything else renders as escaped text. `url.test.ts` covers the refused schemes.
- **Jooble `Debug`:** the key is redacted. The key is validated as one safe path segment.
- **Dependencies:** only `feed-rs` (tech-stack pinned) and its transitive `mediatype` were added. `cargo deny` is clean, so no advisory ignore was added.
- **Migrations:** none in the diff.
