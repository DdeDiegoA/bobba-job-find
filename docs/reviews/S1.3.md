## Acceptance criteria

- **AC1** ✅ — `scripts/gen-bindings.mjs` exports via `ipc::tests::export_bindings`, formats with Biome, and has a `--check` mode that exits 1 when stale. S1.8's web job runs it then `git diff --exit-code src/lib/ipc/bindings.ts`. `bindings.ts` is committed and up to date (verified).
- **AC2** ✅ — `boba_app::error::AppError { code: ErrorCode, message_key: String, details: Option<BTreeMap<String,String>> }`, serialised as `{code, message_key, details}` (unit-tested, `details` omitted when absent). The UI translates **only** `message_key` (`renderAppError`), and the vitest suite asserts the raw key and details never reach the screen. `ErrorHandlingMode::Result` gives the `{status:"ok"|"error"}` envelope in `errors.ts`.
- **AC3** ✅ — `TaskProgressed` (`task.progressed`) and `TaskFinished` (`task.finished`) are typed specta events; `TaskRegistry` + `TaskHandle` (tokio-util `CancellationToken`) provide `begin`/`progress`/`finished`/`cancel`, surfaced by the `task_cancel` command. Unit-tested (cancel marks the task, unknown id is a no-op, finished unregisters).
- **AC4** ✅ — bindings are generated by the script; `command_list.rs` carries the append-only `boba_commands!`/`boba_events!` macros and is `merge=union`; `ipc/mod.rs` is the single `Builder` site and is documented "never register here".

## Design / AD-3 conformance

- Single `tauri_specta::Builder` in `ipc/mod.rs`, wired once in `lib.rs` (`invoke_handler` + `mount_events` + `app.manage(TaskRegistry)`).
- Event names are past-tense facts (`task.progressed`, `task.finished`).
- `commands/registry.rs` retired; `.gitattributes` now marks `ipc/command_list.rs merge=union` — matches the AD-3 ruling of 2026-10-05 and the S1.3 `notes`.
- The append comment sits above a stable marker line in each macro, so union merges of two parallel appends stay conflict-free.

## Non-blocking notes

1. **P3 — fallback key must exist.** `renderAppError` falls back to `UNKNOWN_ERROR_KEY = "errors.unknown"`, and `task_cancel` uses `errors.task.missing_id`. Neither key is in `locales/*` yet (S1.4 owns `common.json`). If a message is ever rendered before S1.4 lands, the *raw i18n key* (`errors.unknown`) is shown. Not a raw Rust string, so AC2 holds, but the two keys must be added in S1.4. (The vitest fallback test currently asserts the raw key is acceptable.)
2. **P3 — `lib.rs` outside `files`.** S1.3 edited `src-tauri/src/lib.rs` to wire `ipc::builder()`; `lib.rs` is not in S1.3's `files`. Unavoidable for IPC wiring (S1.1 could not know the Builder). Ask pm to add `src-tauri/src/lib.rs` to S1.3 `files` (or record the one-time wiring exception).
3. **P3 — `specta-typescript` not in `tech-stack.md`.** Pinned `=0.0.12` as a direct workspace dep; it is tauri-specta's TS exporter. Add the row (architect) for completeness.
