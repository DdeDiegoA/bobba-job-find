## Per-item check

1. **Incremental off (dev + test profiles)** — `Cargo.toml`. Build-cache only; no code effect.
2. **Vitest 15s timeout** — `vite.config.ts`. Test-only.
3. **Workspace dropped before terminal event** — `boba-agent/src/runtime/mod.rs`. `drive()` now owns the sandbox and drops it before emitting the terminal event. The workspace-exists assertion no longer polls. Verified the terminal event is emitted after the drop.
4. **Supervisor reader joins bounded (2s grace, stdout + stderr)** — `boba-agent/src/supervisor/mod.rs`. The stdout channel is an unbounded `std::sync::mpsc` channel, so the reader never blocks on send. Detaching it after the grace cannot drop lines the consumer has not yet received. New test `a_grandchild_holding_stdout_does_not_hang_wait`. The kill-tree test now syncs on a pid file and checks liveness with `kill -0`.
5. **Scheduler clock injected** — `src-tauri/src/scheduler/mod.rs`. `now` and `offset` are read once per tick and passed down. The locked-slot test now asserts `== 1`, not `<= 1`; the fixed 09:00Z instant is after the 08:00 daily search, so the assertion is valid.
6. **CDP call timeout configurable (90s default)** — `boba-browser/src/driver/mod.rs`. `with_call_timeout` added; all call sites use `self.call_timeout`. No other `CALL_TIMEOUT` references remain.
7. **Embeddings `model_version` 2 vs 1** — `boba-domain/src/scoring/rank/mod.rs`, `boba-app/src/scoring/mod.rs`. `score()` and `ScoreRequest::versions()` both use `model_version(semantic.is_some())`, so the card's own version and its store key agree. Store lookup (`scoring.rs:65`) keys on the same value. Cards previously stored under v1 with embeddings are re-scored once; acceptable.
8. **Audit Log pagination + batched status query** — `boba-app/src/stats/audit.rs`, `boba-store/src/repos/applications.rs`, `src-tauri/src/commands/audit_stats.rs`, viewer. Limit clamped to `[1, 200]`; cursor is the entry id, so it survives new rows. Status history is one query (`all_status_events`, ordered `created_at, id`). Tests cover no-gap/no-repeat paging, clamping, and single-query cost. Viewer tests pass.
