## Findings

**F1 (low): `appliedAt` compares timestamps as strings.** `src/features/tracker/nudges/due.ts` `appliedAt()` uses `event.created_at > latest`. The production clock formats with the `time` crate's RFC 3339, which trims trailing zeros. So `…:00Z` sorts after `…:00.5Z`, which is earlier. Effect: the wrong "entered Applied" time is picked only when two Applied events fall in the same wall-clock second. Practically unreachable through the UI. Suggested fix: compare `Date.parse(...)`. Not blocking.

**F2 (nit): misleading doc.** `boba-app/src/apply/guard.rs` `DuplicateGuardView.days_ago` says "Whole local days", but the value is computed from UTC RFC 3339 timestamps. Reword to "whole days". Not blocking.
