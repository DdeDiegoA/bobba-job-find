## Non-blocking notes (follow-ups, not required for this slice)

- **N1 — silent 500-offer cap:** `OFFER_PAGE = 500` (`src-tauri/src/commands/offers.rs:26`) reads only the newest 500 offers, with no notice when the list is cut. Dev-3 disclosed this and pagination is owned by S5.x. The S5.x slice should either add pagination or a visible "showing newest 500" notice.
- **N2 — per-offer queries:** `OffersInbox::cards` (`src-tauri/crates/boba-app/src/offers/mod.rs:150-156`) runs two queries per offer (`offer_sources` and `latest_card`), so one read can run up to about 1,000 queries. Acceptable for a local SQLite store at this size. Worth batching when S5.x adds paging.
- **N3 — Biome warnings:** the three `noExplicitAny` warnings are in the generated `src/lib/ipc/bindings.ts` (Tauri event wrapper), not in S6.4-authored code. They are warnings, not errors.
