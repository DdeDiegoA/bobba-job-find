## Defects found and fixed in this review

- **F1 (medium, security-adjacent, fixed in `66588e9`)** — `host_of` split the authority with `rsplit('@')`, while browsers parse it differently. `https://evil.com\@boards.greenhouse.io/x` and `https://evil.com#@boards.greenhouse.io/x` were labelled "ATS Form · Greenhouse", but the browser (and the "Open original page" button) visits `evil.com`. Verified against WHATWG URL parsing. Fix: the authority must be ASCII alphanumerics, `.`, `-`, `:` only; otherwise no host, so neither ATS Form nor Manual. Regression test `an_authority_a_browser_reads_differently_is_not_an_ats_form`.
- **F2 (low, fixed in `66588e9`)** — Manual was emitted for any string (for example `not a url`), so the bar offered an open button that could not work. Manual and ATS Form are now emitted only for `http(s)` hosts. Test `a_string_that_is_not_an_http_url_has_no_manual_channel`. Defense in depth: the opener default scope only allows `http(s)`, `mailto` and `tel`.
- **F3 (low, fixed in `66588e9`)** — `copy` did not await `clipboard.writeText`, so rejections were unhandled and "Copied" showed even on failure. It now awaits in try/catch and sets "Copied" only on success.
