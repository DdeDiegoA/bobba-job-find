## Findings

### F1 — HIGH (correctness): a FLAG masks a later VETO in `language()`

`scoring/gates/mod.rs` `language()` returns on the first required language in span order. A `Some(declared) if below bar` arm returns FLAG immediately, so a later required language that is undeclared (VETO) is never checked.

- Repro (probed on a scratch copy of `ef5e8d5`):
  - Profile languages: `[es, B1]` only.
  - Posting: `"Spanish (C2) is required. German is required too."`
  - Actual: `Language` = **FLAG**, `BelowRequiredLevel`, quote "Spanish (C2) is required".
  - Expected: **VETO**, `RequirementNotMet` (German is required and undeclared). The report verdict would also be wrong (FLAG instead of VETO), so a posting that must be excluded ranks as merely flagged.
- Fix: evaluate every required language and keep the worst verdict (VETO beats FLAG beats PASS), choosing the quote of the decisive one. Add a golden test for this exact posting.

### F2 — MEDIUM (correctness): lexicon matches have no word boundaries

`scan::demands` and `scan::required_languages` use plain `str::find`. Eligibility phrases such as `us only` match inside other words.

- Repro (probed): posting `"Our focus only on quality. Relocation not needed."`, default candidate (EU work permit, no US).
  - Actual: `Eligibility` = **VETO**, quote "Our focus only on quality", `RequirementNotMet`.
  - Expected: PASS or FLAG `Unverified`. "focus only" is not a US-only demand.
- Same class: `us citizen` in "bus citizen", `eu only` in other tokens, and `native` in "alternative" (the requirement-word list in `scan.rs`). The last one is not triggered by a probe yet, but it has the same root cause.
- Fix: require a word boundary before and after every lexicon match (an ASCII-alphanumeric check on the neighbouring bytes in the folded text is enough). Add a golden test for "focus only" and "alternative".

### R1 — AC wording ruling (not a defect): structured-field evidence

dev-3 asked whether compensation, deadline and work-mode gates must carry a quoted span. Ruling: **accept `Evidence::Field`** for those gates. AC1 asks for "a quoted span", but those values come from structured `Offer` fields (`money`, `deadline`, `work_mode`); a span would have to be guessed from free text, which AD-8 forbids. The `Evidence` enum documents this. The reviewer recommends the orchestrator record this ruling in the wave log so S6.3 and the UI can rely on it.
