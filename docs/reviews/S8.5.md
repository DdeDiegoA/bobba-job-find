## Findings and fixes

- **R1 (HIGH, fixed at 7d120d0):** a refresh that omitted the refresh token stored `None`. The next expiry then needed a new consent. Tests: `a_renewal_that_omits_the_refresh_token_keeps_the_stored_one` (oauth), `a_refresh_that_omits_the_refresh_token_keeps_the_stored_one` (gmail_read, gmail send path).
- **R2 (HIGH, data loss, fixed at 23ecf41 / 7377772):** the first version read the newest 100 ids, then moved the cursor past older mail. The walk was then bounded by a round budget, and then by a before-bound. Both still returned the tail of a non-bottom page. The final version follows `nextPageToken` until the last page and reads its oldest tail. `MAX_LIST_PAGES` = 400 returns an empty answer with a warn log.
- **R3 (MEDIUM, fixed at 7d120d0):** `EmailAccount::covers` used Graph scope names. A Gmail row could never be switched to read+send (`NeedsReconsent`) and could never be set to send-only. Tests: `gmail_coverage_is_googles_scopes_not_graphs`, `a_gmail_mode_switch_is_judged_by_google_scopes`.

## Residuals (after the standing OK on the residual split)

Fixed in the slice (`102266d`, `290cc14`): a 401 renews the access token once and repeats the request, and a second 401 asks for authorisation again. 429 and 5xx are retried up to three times with `Retry-After` (capped 30 s) or 250 ms doubling; 403 is never retried.

Accepted and documented (`docs/qa/gmail-byo-read.md` and the connect-form note):

1. **Google OAuth "Testing" status:** BYO projects left in Testing issue refresh tokens that expire after 7 days. The user must publish the app or re-consent weekly. Document this in the BYO setup text.
2. **Sequential GET per message:** up to 500 `format=full` calls per page of backlog. Slow on a first sync; no concurrency.
3. **Restricted scope:** `gmail.readonly` is restricted. Public distribution of BYO reading still needs Google's verification, and the bundled client stays send-only until CASA (documented, AC1).
4. **Shared refresh path:** the Graph refresh-token fix (`TokenSet::renewed`) touches S8.1's Graph code. It is one line at the call site and covered by tests.
