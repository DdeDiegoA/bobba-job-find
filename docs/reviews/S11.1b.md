## Residuals (for Diego)

1. **Windows lock format unverified.** `SingletonLock` as a file holding `<host>-<pid>` is documented as unverified on Windows; the sign-out check may not fire there. Verify on a Windows box before v1.
2. **Effective minimum delay is 18 s, not 30 s.** Pacing is 30 s with 40% jitter; the doc now states the 18 s floor.
3. **Untrusted-content tag is end to end, not yet enforced by type.** Scraped payloads are documented untrusted and normalised with ammonia; no taint field exists in code. Relies on the S2.4 lockdown gate for any LLM step.
4. **Session-board registration swallows an opted-in read error.** If `opted_in_ids()` fails, the boards are left out of the run (fail closed, no run) rather than reported. Acceptable, but differs from the rows read, which fails the whole run.
5. **Run-level page-load audit is best-effort per source.** An audit read or write failure refuses that page load; the run continues with the other sources.
