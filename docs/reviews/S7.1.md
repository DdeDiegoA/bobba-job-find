- **AC2** ✅ — OFL fonts bundled (`templates/fonts/Lato-{Regular,Bold,Italic}.ttf` + `OFL.txt`, Latin Extended for ES); the render test asserts Lato is embedded (no system fallback). `Template::{DEFAULT_CV, DEFAULT_COVER, ALL, parse, name}` give a stable default + name→template resolution (setting persistence/UI is S7.7).

## ADR-010 (untrusted strings) — verified

Strings go into Typst as **data** (`Value::Bytes` in `sys.inputs.data`) and templates print them as values (`#doc.summary.text`), never as markup source. The test `markup_in_strings_is_rendered_as_text_not_evaluated` injects `#(1+1) #eval("1+1") = heading` and asserts the payload appears **literally** and `"2"` is absent. Render failures (`UnsupportedSchema`, `WrongTemplate`, compile/PDF) are surfaced as errors, never attached to a submission (AD-14).
