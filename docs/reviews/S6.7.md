## Findings

### F1 — Cmd/Ctrl+Z restores a dismissal after the 6 s Undo window (medium)
- **Where:** `src/features/inbox/keyboard/index.tsx` (the `lastDismissed` ref, set in `onDismiss`, cleared only in `onUndo`).
- **Failure scenario:** D dismisses an Offer, the 6 s toast expires, and later the user presses Cmd/Ctrl+Z in the Inbox. `lastDismissed` still holds the id, so `undo` runs and the Offer comes back. The core has no time check either (`boba-app/src/triage/mod.rs:240`, `undo_dismiss`). The window is only enforced by the toast, which the spec's "6-second Undo" does not allow for.
- **Expected:** Cmd/Ctrl+Z works only while the Undo window is open (`UNDO_WINDOW_MS`).
- **Fix:** clear `lastDismissed.current` after `UNDO_WINDOW_MS` (a timer set in `onDismiss`, cleared on undo/unmount). Add a fake-timer test: dismiss, advance past the window, Cmd+Z, and assert `inboxUndoDismiss` is not called.

### F2 — `aria-controls` points at a missing element when there are no rows (low, a11y)
- **Where:** `src/app/palette/index.tsx` (the combobox input, `aria-controls="palette-rows"`).
- **Failure scenario:** the query matches nothing. The `#palette-rows` listbox is not rendered, so the combobox references a missing id.
- **Fix:** set `aria-controls` only when rows exist, or only when the listbox is rendered.

### F3 — `Row` `onKeyDown` Enter branch is unreachable (low)
- **Where:** `src/app/palette/index.tsx`, `Row`.
- **Detail:** rows are never focused (focus stays in the input, `tabIndex={-1}` is only for click focus, and a click already calls `onChoose`). The branch is dead code.
- **Fix:** remove it, or add a test that proves it fires.
