## Adversarial notes

- **i18next dotted keys** — I checked the flat `"errors.unknown"` key resolves through i18next's default `keySeparator:"."` (probe run against the installed i18next: returns the text, not the key). No `keySeparator:false` needed.
- **Core embed** — `boba-app/src/i18n` embeds `locales/{en,es}/common.json` at compile time via `include_str!`; `translated()` reads flat dotted keys with `serde_json::Value::get`; unknown keys return `None` (tested). Invalid JSON panics at first use (fail-loud, acceptable).
- The unused-key rule counts a bare `t("key")` in any namespace, which is intentionally permissive (no false failures); a wrong-namespace match won't fail the build.
