## Findings

### 1 — P2 · `pnpm lint` fails; no `biome.json`

**Repro (in the worktree):**
```
pnpm lint                        # == biome check .
# → Found 8010 errors in 3255 files (scans outside the project: ~/.claude/...)
npx biome check src --max-diagnostics=500
# → 67 `format` diagnostics + 2 `parse` errors (Tailwind CSS directives)
```
**Cause:** `package.json` declares `"lint": "biome check ."` but there is **no `biome.json`/`biome.jsonc`** in the branch (`git ls-tree -r hermad/S1.1 | grep biome` → empty). Biome then runs with defaults: it reformats the project's own files (67 `format` diffs), fails to parse the Tailwind CSS in `src/styles/*.css` (needs `css.parser.tailwindDirectives`), and — with no configured root/includes — walks outside the repo.
**Impact:** the repo's own lint script is unusable; S1.8's CI "Biome" step would fail on the first run.
**Fix:** add `biome.json` (schema 2.x) with `css.parser.tailwindDirectives: true`, an explicit include of `src/**` (+ root config files), and formatter settings matching the committed code; re-run `pnpm lint` → exit 0. Add `biome.json` to S1.1's `files` in `slices.yaml`/`backlog.md` (see finding 4).

### 2 — P2 · AC8: tray is declared but never registered

**Location:** `src-tauri/src/lib.rs` — `mod tray;` is declared and `tauri` enables the `tray-icon` feature, but `run()` never builds a tray (no `tray::init`/`TrayIconBuilder`; `src-tauri/src/tray/mod.rs` only re-exports `kill_switch`, `menu`, `run_controls`).
**Why it matters:** AC8 requires the tray to be registered *so later slices do not edit `lib.rs`*. As it stands, S1.6 (System tray) must edit `lib.rs` to create it, breaking that guarantee.
**Fix:** add a minimal, feature-gated tray init in the builder's `setup` (e.g. `tray::init(app.handle())?` creating an empty `TrayIconBuilder` with the app icon), leaving menu/behavior to S1.6.
