## Acceptance criteria

- **AC1 (URL fetch, robots, fallback to text): met with a spec gap, see Finding F1.** The fetch goes through the shared `HttpClient` (robots and per-host bucket apply). Redirects are followed by hand, each hop re-checked, bounded at 5. Error statuses and a robots disallow are failures, and the UI switches to text mode on `errors.manual.fetch_failed`. Tests: `a_pasted_url_is_fetched`, `robots_rules_block_the_fetch` (page requested 0 times), `a_redirect_is_followed_to_the_page`, `a_redirect_loop_stops_instead_of_fetching_forever`, `an_error_status_is_a_fetch_failure`, frontend `asks for the text when the page cannot be fetched`.
- **AC2 (text → Offer, Source "Manual"): met.** `ManualIntake::from_text` registers the `manual` source, stores the Offer and keeps provenance. Test `the_intake_stores_an_offer_under_the_manual_source`; frontend `creates an Offer and shows it with Source Manual`.

## Security (AD-7, AD-10)

- Stored HTML goes through `normalize` (ammonia). Test `a_fetched_page_is_sanitised_before_it_is_stored` covers `<script>` and `onerror`. Pasted text is escaped before it is wrapped in `<p>`.
- Pasted URL restricted to http/https (`file:`, `javascript:` refused). Redirect targets restricted to http/https.
- Body cap comes from `HttpClient` (4 MiB). Paste cap 1 MiB.
- No page or paste content reaches an agent prompt in this slice.

## Findings

**F1 — spec gap, needs orquestador decision (not a code defect).** AC1 reads "…and the agent extracts an Offer". The implementation extracts deterministically (JSON-LD, then OpenGraph, then `<title>`, then text heuristics) and never invokes the agent. The module doc states this deferral to S6.2. `docs/product/slices.yaml` gives S6.2 the LLM-proposed features (`deps: [S4.2, S2.4, S4.7]`), so the deferral fits the backlog, but the S4.7 AC text was not amended. Options:
1. Recommended: orquestador waives AC1's agent clause for S4.7 in writing, and S6.2 owns agent extraction. Amend the S4.7 AC wording in `stories.yaml` / `slices.yaml`.
2. Dev-3 wires the agent call into the fetch path now. This would conflict with S6.2's ownership of `extract_postings`.

**F2 — minor, non-blocking.** The posting identity for a pasted URL is the trimmed URL string as typed. Re-pasting the same job with different tracking parameters yields a second Offer until S4.3 dedup lands. Expected by the slice boundary; noted for S4.3.

**F3 — minor, non-blocking.** The fetch does not check `Content-Type`. A non-HTML 200 body (e.g. a PDF) is stored as sanitised text. Acceptable for MVP; consider a `text/html` check in a follow-up.

## Verdict

Code, tests and the full CI gate pass. **Not yet approved: waiting on the F1 decision.** Once the orquestador records the waiver (option 1), this is an approve. Option 2 needs a dev-3 round before re-review.
