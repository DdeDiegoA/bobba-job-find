Usage: claude [options] [command] [prompt]

Claude Code - starts an interactive session by default.

Options:
  -p, --print                       Print response and exit (non-interactive)
      --output-format <format>      Output format: text, json, stream-json
      --input-format <format>       Input format
      --json-schema <schema>        JSON Schema for structured output
      --mcp-config <file>           Load MCP servers from a JSON file
      --strict-mcp-config           Only use MCP servers from --mcp-config
      --allowedTools <tools...>     Comma-separated list of allowed tools
      --permission-mode <mode>      Permission mode
      --max-turns <n>               Maximum number of agentic turns
      --max-budget-usd <amount>     Maximum USD budget for the session
      --no-session-persistence      Disable session persistence
      --model <model>               Model to use
  -h, --help                        Display help
