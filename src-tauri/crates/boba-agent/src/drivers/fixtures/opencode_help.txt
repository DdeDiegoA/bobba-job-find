Usage: opencode [command] [options]

Commands:
  run [message...]     Run opencode with a message
  models               List available models
  auth                 Manage authentication

Options:
      --format <format>        Output format (default, json)
  -m, --model <model>          Model to use (provider/model)
      --mcp                    Enable MCP servers from opencode.json
  -p, --permission <perm>      Tool permission (ask, allow, deny)
      --print-logs             Print logs to stderr
  -h, --help                   Display help
